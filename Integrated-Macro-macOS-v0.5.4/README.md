# Integrated Macro 0.5.4

Apple Silicon Mac · macOS 13 이상용입니다.

## 업데이트

1. F4로 중지한 뒤 기존 앱을 완전히 종료하세요. 창 닫기만으로는 부족합니다.
2. 새 `Integrated Macro.app`을 실행하고 버전 0.5.4를 확인하세요.
3. 화면 기록·입력 권한을 확인하고 예매창을 다시 연결하세요. 창 크기·배율이 바뀌었다면 좌표도 다시 지정하세요.

## 실행 방법

- **F7:** 앞쪽 예매창 연결.
- **F8:** 앱에서 항목을 선택한 뒤 예매창의 대상 위에 마우스를 놓고 지정.
- **F1:** 공통 좌석 색상·영역으로 ‘좌석 바로 탐색’ 시작.
- **F2:** 설정한 취소표 탐색 시작. **F4:** 즉시 중지.

일반 예매의 ‘캡챠 Enter 후 구역부터 자동 진행’을 켜면 Enter마다 탐색을 다시 시작합니다. 오답 재제출도 이전 대기 클릭을 취소하고 다시 진행합니다. 완료 버튼 클릭 전달 시 실행을 종료하며, 예매 성공을 확정하지는 않습니다.

## 반복 탐색과 안내창

취소표 내부 새로고침은 ‘한 구역 · 취소표 새로고침 버튼’ 방식 선택·‘취소표에서 버튼 사용’ 켜기·좌표 지정이 필요합니다. F5는 보내지 않습니다. 버튼을 끄거나 좌표가 없어도 탐색은 계속하며, 일부 선택 추정이 남으면 갱신을 보류합니다.

안내창 자동 대응은 중앙 변화나 주변 어두워짐을 픽셀로 추정해 Esc를 보냅니다. 문구를 판독하지 않아 오탐이 가능합니다. 실제 선택 결과를 확인하세요.

## 검증

JavaScript 97개, Rust 144개(플랫폼 7개 포함) 통과. Swift arm64/x86_64 합성·ABI 검사와 Mac arm64 앱 빌드·서명 검사도 통과했습니다. Intel용 앱은 포함하지 않습니다.

실제 Mac 예매창 입력·캡처 및 Windows 빌드는 이번 검증에 포함되지 않았습니다.

동봉한 `input-check.html`을 Chrome으로 열면 실제 예매 없이 F8 지정과 예약 클릭을 시험할 수 있습니다. 이 페이지는 좌석·캡챠 동작 전체를 검증하지 않습니다.

검증 기록은 `verification/`에 있습니다. 앱은 로컬 서명이며 Apple 공증은 아닙니다. 기존 앱과 같은 설정 파일을 사용하지만, 설치된 이전 앱을 자동 교체하지 않습니다.
