# NOL 좌표 매크로 0.4.0 — 검토용 배포

브라우저의 버튼 좌표와 좌석 검색 범위·색을 직접 지정하는 독립 실행 버전입니다. 확장 프로그램, 내부 URL, CSS 선택자, 사이트와의 메시지 연결은 필요하지 않습니다. 외부 통신은 사용자가 등록한 HTTPS 시각 API를 측정할 때 보내는 3회 요청뿐입니다.

## 실행

- **Mac:** `NOL Coordinate Macro.app`을 원하는 고정 위치에 옮겨 실행합니다. macOS 13 이상용이며 Apple Silicon/Intel 코드를 함께 포함합니다. 앱의 **권한·사용법** 탭에서 화면 기록과 손쉬운 사용 권한을 허용한 뒤 앱을 다시 실행하세요. 개발자 인증·공증을 받은 앱은 아니며, 로컬 ad-hoc 서명만 되어 있습니다. 시스템이 실행을 차단하면 시스템 설정의 개인정보 보호 및 보안에서 해당 앱을 확인해 허용해야 합니다. 기존 확장 프로그램이나 Native Host 설치는 필요 없습니다.
- **Windows:** ZIP 전체를 쓰기 가능한 폴더에 풀고 `Start-Macro.cmd`를 실행합니다. AutoHotkey v1.1.37.02 64비트 런타임을 포함하여 별도 설치가 필요 없습니다. Chrome/Edge의 일반 데스크톱 창을 사용하세요. 시각 측정에는 Windows PowerShell 5.1 이상이 필요합니다. `Self-Test.cmd`는 실제 클릭 없이 설정·색 비교 등 16개 검사를 실행합니다.
- Mac은 Chrome/Edge/Safari를 인식합니다. Windows 런타임과 Intel Mac에서의 실제 동작은 이번 환경에서 실행 검증하지 못했습니다. 검증 결과는 `검토결과.md`를 참고하세요.

## 처음 설정하는 순서

1. 대상 브라우저를 전면에 두고 **F7**을 누릅니다.
2. 앱에서 채집 항목을 고릅니다. 브라우저의 해당 위치 위에 마우스를 놓고 **F8**을 누르면 좌표와 필요한 색이 저장됩니다. F8 자체는 클릭하지 않습니다.
3. 일반 티켓팅 탭에서 **좌석 범위 ↖/↘, 남은 좌석의 색, 선택 완료**를 설정합니다. 구역부터 들어갈 때는 **구역 이동** 좌표도 설정하고 해당 옵션을 켭니다.
4. 좌표 확인 체크를 켠 뒤 브라우저로 돌아가 **F1**로 즉시 시작하거나, 취소표 설정 후 **F2**로 시작합니다.
5. **F3**은 항상 긴급 중지입니다. Mac에서 기능키가 밝기·음량으로 동작하면 `fn`과 함께 누르거나 표준 기능키 설정을 사용하세요.

Mac 좌표는 브라우저 창 왼쪽 위 기준, Windows 좌표는 브라우저 클라이언트 영역 기준입니다. 색도 Mac `#RRGGBB`, Windows `0xBBGGRR`로 다릅니다. 운영체제 간 숫자를 그대로 복사하지 말고 F8로 다시 채집하세요.

공연별 지도 크기·확대율·좌석 배치는 자동으로 알아내지 않습니다. 실제 예매 화면에서 한 번은 좌표와 범위를 준비해야 합니다. URL만으로 내부 지도의 좌표를 생성하는 기능은 없습니다. 창 크기, 브라우저 배율, 화면 배율, 스크롤과 좌석 지도 확대 상태를 유지하세요. 배치가 달라졌다면 다시 지정해야 합니다.

## 서버 시각에 맞춘 시작

1. **시각·진입 / 예약·구역 진입** 탭에 시각 API 주소와 응답 형식을 입력합니다.
2. 응답이 JSON이면 필드 경로를 입력합니다. 예를 들어 `{"data":{"timestamp":1790000000123}}`는 `data.timestamp`입니다. 본문 자체가 숫자 또는 ISO 문자열이면 경로를 비웁니다.
3. 한국시간을 `2026-12-05 18:00:00.000`처럼 밀리초까지 입력합니다. 이 값은 형식 예시이며 실제 공연 시간이 아닙니다.
4. **시각 측정**을 누른 뒤 브라우저에서 **F4**를 누릅니다. 목표 시각에 등록한 예매 버튼 좌표를 **한 번** 클릭합니다. 10분 이내에 측정한 값으로 예약을 시작해야 하며 목표는 12시간 이내 미래여야 합니다.
5. 대기열을 기다리고 **캡챠는 직접 입력**합니다. 구역 지도가 준비되면 **F6**으로 구역 → 좌석 탐색을 시작합니다. 새 예매 창이 열린 경우에는 그 창에서 **F7로 재연결한 뒤 F6**을 누릅니다. 새 창의 배치에 맞춰 미리 준비한 좌표가 필요합니다.

예약 클릭 이후 전체 실행 제한은 15분에 좌석 탐색·후속 단계 제한을 더한 값입니다. 더 긴 대기열에서는 중지될 수 있으며, 실제 구역 화면에 들어간 뒤 F1로 다시 시작할 수 있습니다.

형식은 `milliseconds`(Unix 밀리초), `seconds`(Unix 초), `iso`(시간대가 포함된 ISO 시각), `date`(HTTP Date 헤더)입니다. Date는 HEAD, 나머지는 GET을 사용합니다. 로그인 쿠키를 붙이지 않으며 리디렉션과 명시적인 캐시 응답은 거절합니다.

사이트의 상품 URL을 넣는다고 정확한 예매 서버 시각 API로 바뀌지는 않습니다. 실제 API는 사용자가 등록해야 하며 이 배포본에 NOL의 시각 API를 추정해서 내장하지 않았습니다. HTTP Date와 정수 초 응답은 밀리초 정밀도를 제공하지 않습니다. 표시하는 RTT/추정 오차는 네트워크 왕복시간과 응답 해상도를 이용한 참고값이며, 원격 서버 자체의 시계 오차까지 보증하지 않습니다.

**준비 픽셀 자동 재개**는 선택 기능입니다. 예약 클릭 이후 지정 색과 불일치를 관찰한 다음, 일치 상태를 두 번 확인하면 구역 탐색을 재개합니다. 캡챠 화면이나 대기열에서도 같은 색이 나오는 위치는 쓰지 마세요. F7로 새 창을 연결하면 이번 실행의 자동 재개는 꺼지고 F6을 기다립니다.

Windows에서 압축 파일의 다운로드 표시나 조직 정책 때문에 `ClockSync.ps1`이 차단되면 시각 측정이 실패합니다. 스크립트 내용을 검토하고 파일 속성에서 차단 여부를 확인하세요. 프로그램은 시스템 실행 정책을 영구 변경하지 않습니다.

## 경합 후 다른 좌석

**경합·전환** 탭에서 실제 경합 안내가 뜰 때만 함께 나타나는 서로 다른 두 위치의 색과 안내 닫기 좌표를 지정합니다. 두 표식이 일치하면 안내를 닫고, 실패한 좌석 주변을 제외한 다음 후보를 찾습니다. 실패 목록은 실행별로 유지하며 F1/F2로 새로 시작하면 초기화합니다.

기본적으로 꺼져 있으므로 실제 표식을 지정한 뒤 켜야 합니다. 문구를 읽거나 서버 응답을 해석하지 않습니다. 다른 오류창과 같은 색을 쓰면 잘못 분류할 수 있습니다. 여러 좌석을 고르는 중에는 실패한 좌석을 화면 색만으로 특정할 수 없어 중지하는 경우가 있습니다. 경합 대응은 1석 기준으로 먼저 확인하세요.

좌석의 색 변화는 화면 반응일 뿐 확보 확정이 아닙니다. **가격 화면 준비 색 대기**도 함께 지정하면 선택 완료 후 경합 안내 또는 다음 화면 전환을 기다릴 수 있습니다. 이 옵션을 끄고 후속 클릭도 사용하지 않으면 선택 완료 버튼을 누른 뒤 종료하므로, 그 뒤 늦게 뜨는 경합 안내에는 대응하지 않습니다.

## 취소표

**F2 취소표 기능을 유지했습니다.** 현재 1구역의 검색 범위와 색만 탐색하거나, 지정한 두 구역 이동 버튼을 번갈아 클릭해서 각 구역을 다시 확인할 수 있습니다. 취소표는 1석을 선택하며 탐색 제한 기본값은 1시간입니다.

현재 화면에 표시되는 좌석만 읽습니다. 사이트가 좌석 정보를 갱신하지 않는 화면에서는 새 취소표를 알 수 없으므로 화면을 재조회하는 구역 이동 좌표가 필요합니다. 새로고침이나 좌석 API 요청을 따로 보내지는 않습니다.

## 선택 완료 뒤 추가 클릭

후속 클릭 목록에 좌표를 추가하고 활성 여부·순서·최소 대기·대기 픽셀을 설정합니다. 예: **일반 가격 + 버튼 → 1매 예매하기**. 예매 정보 입력 화면에서 끝나도록 지정하세요.

후속 클릭을 켤 때는 먼저 **가격 화면 준비 색 대기**를 설정해야 합니다. 각 클릭은 한 번씩 실행하며, 다른 화면으로 넘어가는 단계에는 그 화면에서만 나타나는 대기 픽셀을 등록하세요. 가격·수량과 사이트 결과는 직접 확인하세요.

## 보관·검증

- Mac 설정: `~/Library/Application Support/NOLCoordinateMacro/settings.json`. 앱에서 설정 저장을 누릅니다.
- Windows 설정: 실행 폴더의 `data/`. 기존 6개 INI를 가져올 수 있지만 좌표는 다시 확인해야 합니다.
- 기존 v0.3 앱·확장은 별도로 남겨 두었습니다. 동시에 매크로를 실행하지 마세요.
- 두 ZIP 모두 해당 플랫폼 소스와 검토 결과를 포함합니다. Mac 소스 재빌드는 Xcode Command Line Tools가 있는 Mac에서 `bash source/build.sh`입니다.
- 화면 캡처는 메모리에서만 처리하며 녹화 파일을 저장하지 않습니다. 앱을 닫으면 종료됩니다.

이번 배포는 실제 예매 성공이나 다른 사용자보다 빠른 확보를 보증하지 않습니다. 화면 갱신, 운영체제 입력 전달, 사이트 응답 시간이 개입하므로 **0.01초 이내 좌석 확보를 검증한 버전이 아닙니다.**
