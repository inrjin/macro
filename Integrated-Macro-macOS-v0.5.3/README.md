# 통합 매크로 0.5.3 · Mac 창 판정 수정 검증 빌드

Apple Silicon Mac, macOS 13 이상용입니다. 기존 앱을 ⌘Q로 완전히 종료한 뒤
이 폴더의 `Integrated Macro.app`을 실행하고 창 제목의 **0.5.3**을 확인하세요.
기존 설정 파일을 사용합니다. 설치된 기존 앱을 자동 교체하지 않습니다.

## 이번 수정

- F7 연결은 작은 Chrome 보조창 대신 실제 활성 창을 확인합니다.
- 화면 전체 크기의 Dock 항목이 목록에 나타나도 사각형만으로 가림을 단정하지 않습니다.
  macOS 손쉬운 사용 정보로 해당 위치의 실제 창이 연결한 예매창인지 추가 확인합니다.
- 실제 Dock·다른 창의 가림이나 확인 실패는 계속 차단하고 오류 이유를 표시합니다.
- F8은 마우스 좌표와 화면 픽셀을 읽습니다. 사이트 HTML·DOM·로그인 정보를 추출하지 않습니다.

## 사용 순서

1. 실제 예매창을 전면에 두고 **F7**로 다시 연결합니다.
2. 앱에서 필요한 항목의 **F8로 지정**을 누릅니다. 설정창이 최소화됩니다.
3. 연결한 창의 대상 위에 마우스를 놓고 **F8**을 누릅니다.
4. 상단 표시창의 지정 완료 좌표 또는 오류 코드를 확인합니다.
5. 자동 클릭을 시작할 때는 연결한 예매창을 활성화하고 **F1**을 누르세요. **F4**는 중지입니다.

`accessibility_permission`이면 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서
**Integrated Macro**를 허용하고 앱을 다시 실행하세요. `target_focus_unavailable`이면
예매창을 클릭하고 F7로 다시 연결합니다. `target_hit_test_unavailable`이면 Dock·메뉴를
닫고 대상 위에서 F8을 재시도합니다. 진단 스크립트의 `screenPermission` 값은 그 실행
프로세스의 권한이며 이 앱의 권한을 나타내지 않습니다.

예약 실행은 **판매 시작 예매 버튼**을 지정해야 합니다. 날짜·회차·캡챠는 직접 진행하고
실제 좌석 화면에서 F6으로 진입을 확인합니다. 다른 예매 팝업이면 해당 창에서 F7로
다시 연결한 뒤 필요한 항목의 F8 지정을 진행하세요.

## 검증 범위

사용자 제공 창 정보로 재현한 판정 검사, Rust·JavaScript 테스트, Swift 두 아키텍처
컴파일 및 Mac 앱 빌드·번들 서명·소스 해시 검사 결과를 `verification/`에 기록합니다.
이 앱 실행 파일은 **arm64**입니다. x86_64 Swift 검사 통과가 Intel 앱 배포를 뜻하지 않습니다.

**실제 사용자 Chrome의 AX 응답·F8 캡처·마우스 입력·지연은 이 환경에서 검증하지 못했습니다.**
재현 검사에서 AX 응답은 가상 값입니다. 실전 사용 준비 완료로 표시하지 않습니다.
이 앱은 로컬 서명이며 Apple 공증은 아닙니다. Windows 앱은 이번 패키지에 포함하지 않습니다.

동봉한 `input-check.html`은 실제 예매 없이 F8 지정과 예약 클릭 횟수를 확인하는 페이지입니다.
오류 로그는 `~/Library/Application Support/dev.integrated-macro.desktop/runtime-events.jsonl`에 남습니다.
