이 컴퓨터의 시간대

시각은 브라우저가 클릭을 처리한 순간을 밀리초까지 기록합니다. 날짜·시각 뒤의 UTC 차이도 함께 확인하세요.

F8로 위치를 지정하는 동안에는 클릭 횟수가 그대로여야 합니다.

확인 순서

  1. 이 파일을 Google Chrome으로 열고, Chrome 창을 앞에 둔 상태에서 F7을 눌러 연결합니다.
  2. 앱의 예매 준비 → 판매 시작 예매 버튼 → F8로 지정을 누릅니다. Chrome의 보라색 예약 테스트 버튼 위에 마우스를 놓고 F8을 누릅니다.
  3. 앱에서 예약 시작을 켜고, 판매 시작 시각을 이 컴퓨터의 시간으로 약 30초 뒤로 설정합니다. 서버 시간 보정 사용은 끕니다.
  4. 앱에서 일반 예매 모드를 선택하고 일반 예매 시작을 누릅니다. 연결한 Chrome 창이 앞으로 나오는지 확인하고 예약 시각까지 기다립니다. 단축키로 검사할 때는 Chrome 창을 앞에 둔 뒤 F1을 누르세요. F1도 현재 화면의 예약·옵션 설정을 저장해 일반 예매로 시작합니다.
  5. 클릭 횟수 1회와 기록된 시각, 앱의 예매 진입 대기를 확인한 뒤 F4로 중지합니다.

Mac에서 기능 키가 밝기·미디어 조절로 동작하면 Fn과 함께 누르세요. 버튼을 직접 클릭해도 횟수가 올라갑니다. 다시 시험할 때는 기록 초기화를 누르세요.

이 페이지는 파일 안의 코드만 사용합니다. 외부 서버에 연결하거나 실제 예매·결제를 진행하지 않습니다. 페이지를 새로 열거나 새로고침하면 기록이 초기화됩니다.
