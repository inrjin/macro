# Integrated Macro 0.5.5

Apple Silicon Mac · macOS 13 이상용입니다.

## 업데이트

1. F4로 중지한 뒤 기존 앱을 완전히 종료하세요. 창 닫기만으로는 부족합니다.
2. 이 폴더의 `Integrated Macro.app`을 실행하고 화면 왼쪽 아래의 **v0.5.5**를 확인하세요.
3. 화면 기록·입력 권한을 확인하고 예매창을 다시 연결하세요. 창 크기·배율이 바뀌었다면 좌표를 다시 지정하세요.

기존 앱과 같은 설정 파일을 사용합니다. 이전 앱을 자동 교체하지 않습니다.

## 일반 예매와 F1

- **F1:** 현재 화면에서 고른 옵션·목표 매수·클릭 간격을 저장하고 **일반 예매**를 시작합니다. 별도 저장 버튼을 누를 필요가 없습니다. 앱의 실행 방식 선택과 관계없이 일반 예매입니다.
- **F2:** 취소표 탐색. **F3:** 일시정지·재개. **F4:** 즉시 중지.
- **F7:** 앞쪽 예매창 연결. **F8:** 앱에서 항목을 선택한 뒤 예매창의 대상 위에 마우스를 놓고 지정.
- **좌석 바로 탐색:** 앱에서 해당 실행 방식을 선택한 뒤 시작 버튼을 누르세요.

연결한 예매창을 앞에 두고 F1을 누르세요. 설정 읽기·저장에 실패하면 오류를 표시하며 시작하지 않습니다.
F4를 누르면 처리 중인 F1 요청도 취소합니다.

**캡챠 Enter 후 구역부터 자동 진행**을 켜도 먼저 등록된 날짜 → 회차 → 다음/예매 버튼을 기존 클릭 간격으로 누릅니다.
판매 시작 버튼·예약은 선택한 설정에 따라 그 앞에서 실행합니다. 등록하지 않은 단계는 직접 진행하세요.
진입 버튼 처리가 끝난 뒤 캡챠를 입력하고 Enter를 누르면 구역 → 좌석 탐색으로 이어집니다.
캡챠를 다시 제출하면 구역부터 재탐색하며 앞선 진입 버튼을 다시 누르지 않습니다.

좌석이 없으면 계속 탐색합니다. 선택 완료 버튼 입력이 전달되면 종료하며, 실제 예매 성공을 확인한 것은 아닙니다.

## 확인 범위

자동 테스트·빌드·서명 검사 결과는 동봉한 `verification/`에 기록했습니다.
실제 예매창에서의 Mac 입력·캡처·Enter 수신과 Windows 앱 실행은 별도 확인이 필요합니다.
Intel용 앱은 포함하지 않으며 앱은 로컬 서명입니다. Apple 공증을 받은 앱은 아닙니다.

`input-check.html`을 Chrome으로 열면 실제 예매 없이 F8 지정과 예약 클릭을 시험할 수 있습니다.
이 페이지는 좌석·캡챠 동작 전체를 검증하지 않습니다.
