설정

공연 날짜·회차와 로그인은 사이트에서 미리 확인하세요. 예매 버튼이 보이는 위치에서 대기합니다.

1 · 예매 버튼
서버 Date는 초 단위이며 예매 서버와 다를 수 있습니다. 실제 버튼 활성 상태도 반드시 확인합니다.
2 · 좌석 화면 준비 감지 좌석 지도가 모두 로딩된 뒤에만 생기는 요소를 지정하세요. 대기열·캡차 화면의 요소를 지정하면 안 됩니다. 먼저 실제 화면에서 보정이 필요합니다.
3 · 좌석 경합 · 후속 클릭

실제 성공 요소와 실패 문구를 먼저 지정해야 실행됩니다. 아래 연습 프로필은 제공된 연습 페이지 전용입니다.

대기 시작 후 팝업은 닫힙니다. 상품 탭을 전면에 두세요. 브라우저 좌석 작업: Alt+Shift+S 또는 중지 버튼 · Windows AHK: F3
