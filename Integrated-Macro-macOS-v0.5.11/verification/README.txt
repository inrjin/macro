통합 매크로 0.5.11 검증 기록

local-checks.json과 build-and-checks.log는 최종 소스의 자동 검사와 macOS 빌드·서명 결과입니다.
f9-audit-README.md의 링크는 원본 소스 verification/f9-any-state/를 기준으로 하며, 상세 상호 리뷰·재현 자료는 소스 저장소에 보존했습니다.
f9-audit-final-manifest.json은 검토 파일과 최종 소스 해시를 연결합니다.
이 패키지를 실행하거나 실제 사이트에서 예매하지 않았습니다. arm64 macOS 13 이상용이며 Apple 공증은 포함하지 않습니다.
ZIP 자체의 해시·독립 재추출 검사는 원본 소스 verification/release-0.5.11/distribution-receipt.json에 있습니다.
