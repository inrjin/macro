통합 매크로 v0.5.11 · macOS 실험용 배포
Apple Silicon(arm64), macOS 13 이상

업데이트
1. 기존 앱에서 F4로 중지한 뒤 앱을 완전히 종료하세요.
2. 이 패키지의 Integrated Macro.app을 기존 위치에 복사·교체하세요.
3. 실행 후 v0.5.11과 저장된 옵션을 확인하고 예매창을 다시 연결하세요.
구버전과 신버전을 동시에 실행하지 마세요. 앱 식별자와 설정 저장 경로는 유지합니다.
기존 0.5.10 배포 폴더와 ZIP은 보존했습니다.

F9 · 캡챠 이후 진행
캡챠 또는 필요한 수동 진입을 직접 마쳤다면 F9를 누르세요.
실행 대기·중지·예약 대기·입장·구역·좌석·완료 등 현재 실행 단계 때문에 거절하지 않습니다.
이전 작업의 미전달 클릭을 취소하고 날짜·회차·입장 버튼을 다시 누르지 않습니다.
‘무대 중앙 · 가까운 구역 우선’을 켜면 구역부터, 끄면 좌석 탐색부터 진행합니다.
같은 예매창에 전달된 좌석 기록이 있으면 이를 유지하고 부족분 탐색을 이어갑니다.
화면 감지로 확인한 오류창이 해결되지 않았다면 F4 이후 F9에서도 오류창 처리부터 이어갑니다.
전달에 성공한 Esc는 같은 오류에 반복 전송하지 않으며 화면에서 닫힘을 확인합니다.
다른 예매창을 새로 연결하면 이전 창의 선택 기록을 사용하지 않습니다.
네이티브 연결 실패 후 다시 연결한 경우에는 이전 탐색 기록이 초기화될 수 있습니다.
이미 구역 안의 좌석 화면이라면 F5로 좌석부터 탐색할 수 있습니다.

예매창 연결과 입력·화면 기록 권한, 색상·탐색 범위 설정은 필요합니다.
일시적으로 창이 가려지거나 캡처가 지연되면 클릭을 보류하고 예매창 복귀를 기다린 뒤 자동 재개합니다.
권한 거부·연결 없음·화면 크기 변경은 원인을 해결한 뒤 F9를 다시 누르세요.
구역 선택에는 ‘구역 영역’과 ‘무대 정면 중앙’ 지정이 필요합니다.
F9는 사용자의 직접 진행 명령이며 캡챠 정답이나 모든 사이트의 현재 화면을 자동 판별하지 않습니다.

다른 실행 명령
F1·F2·F5와 앱 시작 버튼은 별도로 F4를 누르지 않아도 새 명령으로 재시작합니다.
F1은 처음 입장부터, F2는 취소표 설정대로, F5는 현재 좌석 화면에서 진행합니다.
완료 뒤 명시적으로 다시 실행하면 현재 화면을 재관측한 뒤 재시도합니다.
이미 OS에 전달된 클릭을 되돌릴 수는 없습니다.

날짜·회차·예매 버튼 직접 진행
‘추가 기능’에서 켤 수 있으며 기본 OFF입니다.
ON이면 최초 예약 예매 버튼은 기존 설정대로 누르고 후속 날짜·회차·다음 버튼은 건너뜁니다.
등록된 좌표를 삭제하지 않습니다. 직접 진입한 뒤 캡챠 판단·Enter 또는 F9로 진행하세요.
캡챠 자동 판단·Enter 옵션을 모두 끄면 F9를 기다립니다.

선택 기능과 단축키
‘연석 우선’, ‘좌석 외곽으로 구분’, ‘NOL 선택 좌석 수 확인’은 기본 OFF입니다.
수량 확인을 켜면 읽을 수 있는 사이트 표시가 목표 수량에 도달해야 완료를 누릅니다.
지원하지 않는 글꼴·배치 또는 불명확한 클릭 결과에서는 관측 대기가 계속될 수 있습니다.
F1 일반 예매 · F2 취소표 탐색 · F3 일시정지/재개 · F4 중지
F5 좌석 바로 탐색 · F6 현재 대기 단계 확인 · F7 예매창 연결
F8 선택 항목 좌표 지정 · F9 캡챠 이후 진행
Mac 키보드 설정에 따라 Fn과 함께 눌러야 할 수 있습니다.

검증 범위
검사·빌드·서명·압축 무결성 결과는 verification/의 기록을 확인하세요.
실제 예매 사이트, 물리 단축키·입력, Windows 실행은 별도 검증이 필요합니다.
수량 확인 OFF의 선택 기록은 전달 추정이며 서버 선점·결제 성공 확정이 아닙니다.
좌석 선택 완료 버튼 전달 뒤 결제·최종 성공 확인은 하지 않습니다.

권한과 기록
앱은 로컬 ad-hoc 서명이며 Apple 공증을 받지 않았습니다. 업데이트 후 권한 승계는 보장하지 않습니다.
입력·화면 읽기가 실패할 때 앱 진단에 따라 손쉬운 사용·화면 기록·입력 모니터링을 확인하세요.
설정: ~/Library/Application Support/dev.integrated-macro.desktop/settings.json
실행 기록: ~/Library/Application Support/dev.integrated-macro.desktop/runtime-events.jsonl
문제가 생기면 실패 시각과 앱 실행 기록을 보존하세요.
