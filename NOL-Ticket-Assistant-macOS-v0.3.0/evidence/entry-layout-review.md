# v0.3 구역 진입 · 지도 크기 대응

실제 NOL 인증 이후 구역 화면을 관측했다는 보고서가 아니다. CAPTCHA → 구역 → 실제 좌석 순서는 사용자가 설명한 흐름이며, 이번 변경은 그 흐름을 지원하는 설정 가능한 엔진이다. 실제 공연의 CSS, 구역 식별, 결과 문구 및 지도 렌더러는 아직 미확인이다.

- 구역 픽커는 요소 선택자, 상대 위치, 텍스트/식별 속성을 저장하고 실제 클릭의 기본 동작을 막는다.
- 클릭 직전 DOM/SVG 요소의 현재 경계를 재측정한다. 같은 이미지의 실제 content rectangle은 object-fit/object-position과 여백을 반영한다.
- Canvas 구역은 내부 변환을 알 수 없으므로 자동 구역 지정 대상에서 제외한다. 실제 구조 확인 없이 이미지 유사도나 색만으로 다른 구역을 추측하지 않는다.
- iframe은 자식 WindowProxy를 부모 iframe 요소와 대응시켜 실제 현재 배치를 계산한다. 중첩 프레임은 부모 방향으로 좌표를 누적한다. 회전/기울임/가려짐은 중지한다. 확장의 허용 도메인 밖의 중간 프레임은 지원하지 않는다.
- 수동 확인 패널이 보이는 동안 진입하지 않는다. 패널이 사라지고 구역 준비 조건이 참일 때 한 구역을 클릭한다. 지정 구역의 로딩 완료 조건 뒤에만 좌석 후보를 준비한다. 보안 확인이 다시 나타나면 중지한다. alert 재시도에서도 이 감시를 유지한다.
- 픽셀 검색은 지도 요소의 현재 경계를 사용한다. Chrome PNG가 페이지 아래 빈 공간을 잘라 반환하는 경우를 세로 배율로 오인하지 않도록 수정했다. 후보 준비 뒤 지도 경계가 변하면 이전 좌표를 사용하지 않는다.
- 픽셀 후보는 단일 스크린샷의 색상 연결 성분이다. Canvas 내부 재배치, 같은 이미지 URL의 내용 교체, 실제 구역 이름이 없는 모양의 의미는 일반 방식으로 판별하지 못한다. 후보 색만으로 서버 선점 성공을 판단하지 않는다.

`verification/entry-tests.json`은 외부 HTTP가 차단된 로컬 NOL URL 모의 화면에 실제 MV3 확장을 로드한 결과다. 버튼 클릭은 브라우저 trusted 입력이다. 실제 CAPTCHA나 실제 좌석 서버는 사용하지 않았다.

새 기능은 Windows와 Mac에서 동일한 브라우저 확장 엔진을 사용한다. Mac은 네이티브 SwiftUI 앱에 구역 진입/지도 기준 UI를 추가했다. Windows AHK 좌표 엔진에는 이 구역 식별 기능을 추가하지 않았다.
