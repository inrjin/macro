Mac 전용 배포본 · NOL Ticket Assistant 0.3.0

NOL Ticket Assistant.app을 계속 사용할 위치로 옮긴 뒤 실행하세요.
macOS 13 이상, Apple Silicon/Intel 공용 앱입니다.
앱 → 연결 · 기록 → 확장 폴더 열기 → Chrome/Edge에서 확장 로드 → 확장 ID 등록.
앱 위치가 바뀌었다면 연결을 다시 등록하세요. 기존 버전 확장은 먼저 중지/비활성화하세요.

‘구역 진입’ 탭에서 구역 요소를 지정할 수 있습니다.
먼저 ‘구역 진입 연습 프로필’을 불러오고 연습 페이지에서 ‘구역 진입 연습’을 켜세요.
문자 입력은 직접 하며 이후 지정 구역 1곳에만 진입합니다.
실전 NOL 화면의 구역 식별과 로딩/결과 조건은 별도로 확인해야 합니다.

로컬 ad-hoc 서명이며 Apple 공증은 없습니다. GUI 자동조작 검증은 도구 시간 초과로 미완료입니다.
