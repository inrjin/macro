Integrated Macro 0.5.7
Apple Silicon (arm64) Mac · macOS 13 이상

검증 상태
소스 자동 검사: JavaScript 123개·Rust 190개 테스트를 통과했습니다.
0.5.7 기준 전체 검사, Swift arm64/x86_64 컴파일·네이티브 검사, 앱 빌드·서명 검사를 통과했습니다.
검사 결과와 배포 파일 해시는 동봉한 verification 폴더에 있습니다.
자동 검사 결과와 실제 예매 동작 검증은 구분됩니다. 기존 0.5.6 배포본은 유지합니다.

업데이트와 실행
1. F4로 중지한 뒤 기존 앱을 완전히 종료하세요. 창 닫기만으로는 부족합니다.
2. 이 폴더의 Integrated Macro.app을 실행하고 화면 왼쪽 아래 v0.5.7을 확인하세요.
3. 예매창을 다시 연결하세요. 창 크기·배율이 바뀌었다면 좌표를 다시 지정하세요.

같은 앱 식별자와 설정 저장 경로를 사용하므로 기존 설정을 사용합니다.
이전 앱을 자동 교체하지 않습니다. 두 버전을 동시에 실행하지 마세요.
새 앱에서 화면 읽기나 마우스 입력이 실패하면 시스템 설정 → 개인정보 보호 및 보안에서
손쉬운 사용·화면 기록 관련 항목의 새 앱 권한을 확인하고 앱을 다시 실행하세요.
macOS 버전에 따라 화면 기록 항목 이름은 다를 수 있으며, 업데이트 후 권한 유지는 보장하지 않습니다.

NOL 캡챠 판단 사용
기본 OFF인 별도 옵션입니다. 앱에서 ‘NOL 캡챠 판단’을 켜고 예매창을 앞에 둔 뒤 F1로 시작하세요.
일반 예매에만 적용하며, 등록한 날짜 → 회차 → 다음/예매 버튼의 기존 순서와 클릭 간격을 유지합니다.
미지정 단계와 캡챠는 직접 진행하세요. 처음 NOL 캡챠 창을 확인하면 창 왼쪽 아래 배경 색을 저장합니다.
0.5.7은 25개 표본 중 20개 이상에서 RGB 한 채널 이상이 기준보다 45 이상 달라진 상태가
100ms 유지되면 구역·좌석 탐색으로 진행합니다. 밝아짐·어두워짐·색상 변화 모두 감지합니다.
입력 글자와 버튼 색은 판단하지 않으며, 최초 구역/좌석 클릭 직전에도 같은 배경 조건을 다시 확인합니다.
Enter 진행 옵션도 켰다면 NOL 판단이 우선하므로 Enter만으로 대기를 풀지 않습니다.
문자 자동 풀이 또는 정답 판정 기능이 아닙니다.
해당 배경의 다른 변화나 불투명한 전체 흰색·검정 화면을 실제 캡챠 해제와 구분하지 못할 수 있습니다.
처음 NOL 창을 인식하지 못하거나 배경이 충분히 바뀌지 않으면 대기합니다.
이미 캡챠를 끝낸 좌석 화면이라면 F5 좌석 바로 탐색을 사용하세요.

실행 단축키
F1: 일반 예매
F2: 취소표 탐색
F3: 일시정지 / 재개
F4: 즉시 중지
F5: 좌석 바로 탐색
F6: 원본 흐름에서 현재 대기 단계 직접 확인
F7: 앞쪽 예매창 연결
F8: 앱에서 지정 항목을 선택한 뒤 예매창의 대상 위에서 위치 지정

F1·F2·F5는 저장 전의 현재 화면 옵션을 적용해 각 모드로 시작합니다.
연결한 예매창을 앞에 두고 누르세요. 일부 Mac 키보드는 Fn 키가 필요합니다.
F5는 브라우저 새로고침 기능이 아닙니다.

한 구역 취소표
‘한 구역 · 현재 좌석 계속 탐색’은 현재 좌석 화면에서 공통 좌석 색상·좌석 영역으로 탐색합니다.
새로고침 버튼 사용을 꺼도 탐색을 이어갑니다. 공통 좌석 선택 완료 버튼을 사용하므로
완료 좌표가 없으면 자동 완료 클릭은 할 수 없으며 직접 진행한 뒤 중지하세요.

확인 범위
실제 NOL 정답·오답 입력 뒤 화면 전환과 Windows 앱 실행은 미검증입니다.
좌석 클릭 전달은 선택 추정이며, 완료 버튼 클릭 전달로 종료해도 예매 성공을 확정하지 않습니다.
이 패키지는 Apple Silicon용이며 Intel용 앱은 포함하지 않습니다.
앱은 로컬 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받은 앱은 아닙니다.
