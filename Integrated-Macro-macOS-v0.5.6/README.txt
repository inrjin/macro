Integrated Macro 0.5.6
Apple Silicon Mac · macOS 13 이상

빌드 확인
0.5.6 Mac 앱 빌드와 서명 검사를 완료했습니다.
JavaScript 123개·Rust 178개 테스트, Swift arm64/x86_64 네이티브 검사,
검사 전후 소스 해시 일치 확인을 통과했습니다. 실제 예매 동작 검증과는 구분됩니다.
기존 0.5.5 앱과 ZIP은 변경하지 않습니다.

업데이트와 실행
1. F4로 중지한 뒤 기존 앱을 완전히 종료하세요. 창 닫기만으로는 부족합니다.
2. 이 폴더의 Integrated Macro.app을 실행하고 화면 왼쪽 아래 v0.5.6을 확인하세요.
3. 예매창을 다시 연결하세요. 창 크기·배율이 바뀌었다면 좌표를 다시 지정하세요.

같은 앱 식별자와 설정 저장 경로를 사용하므로 기존 설정을 유지합니다.
이전 앱을 자동 교체하지 않습니다. 두 버전을 동시에 실행하지 마세요.
새 앱에서 화면 읽기나 마우스 입력이 실패하면 시스템 설정 → 개인정보 보호 및 보안에서
손쉬운 사용·화면 기록 관련 항목의 새 앱 권한을 확인하고 앱을 다시 실행하세요.
macOS 버전에 따라 화면 기록 항목 이름은 다를 수 있으며, 업데이트 후 권한 유지는 보장하지 않습니다.

실행 단축키
F1: 일반 예매
F2: 취소표 탐색
F3: 일시정지 / 재개
F4: 즉시 중지
F5: 좌석 바로 탐색
F6: 원본 흐름에서 현재 대기 단계 직접 확인
F7: 앞쪽 예매창 연결
F8: 앱에서 지정 항목을 선택한 뒤 예매창의 대상 위에서 위치 지정

F1·F2·F5는 앱의 실행 방식 선택과 관계없이 해당 모드로 시작합니다.
저장 버튼을 누르지 않아도 현재 화면에서 고른 옵션을 먼저 저장해 적용합니다.
연결한 예매창을 앞에 두고 누르세요. 일부 Mac 키보드는 Fn 키가 필요합니다.
F5는 브라우저 새로고침 기능이 아닙니다.

NOL 캡챠 판단
별도 옵션이며 기본 OFF입니다. 일반 예매에만 적용합니다.
등록된 날짜 → 회차 → 다음/예매 버튼을 기존 순서와 간격으로 처리한 뒤 캡챠를 기다립니다.
캡챠는 직접 입력하세요. 먼저 확인한 NOL 캡챠 창이 사라진 상태를 확인하면 구역·좌석 탐색을 시작합니다.
Enter 진행 옵션도 켰다면 NOL 판단을 우선하므로 Enter만으로 대기를 풀지 않습니다.
문자 자동 풀이 또는 정답 판정 기능이 아닙니다.
현재 판별은 제공된 한국어 NOL 디자인과 주변 흰 배경을 기준으로 하며, 다른 디자인에서는 대기할 수 있습니다.
이미 캡챠를 끝낸 좌석 화면이라면 F5 좌석 바로 탐색을 사용하세요.

한 구역 취소표
일반 예매의 예약·진입·구역 우선 설정을 건너뛰고 현재 좌석 화면에서 시작합니다.
버튼 없이 반복 탐색하려면 ‘한 구역 · 현재 좌석 계속 탐색’을 선택하세요.
새로고침 버튼 사용을 꺼도 탐색을 이어갑니다.
공통 좌석 색상·좌석 영역·좌석 선택 완료 버튼을 사용합니다.
완료 버튼 좌표가 없으면 자동 완료 클릭은 할 수 없으므로 직접 진행한 뒤 중지하세요.
원본 구역별 설정은 두 구역·위/아래 키 이동에서 활성화된 구역에 적용됩니다.

확인 범위
실제 NOL 정답·오답 제출 뒤 화면 전환과 Windows 앱 실행은 미검증입니다.
좌석 클릭 전달은 선택 추정이며, 완료 버튼 클릭 전달로 종료해도 예매 성공을 확정하지 않습니다.
이 패키지는 Apple Silicon용이며 Intel용 앱은 포함하지 않습니다.
앱은 로컬 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받은 앱은 아닙니다.
