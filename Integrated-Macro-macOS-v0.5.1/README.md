# 통합 매크로 0.5.1 · Mac

Apple Silicon Mac, macOS 13 이상용 앱입니다. 기존 실행 중인 통합 매크로를 종료한 뒤 이 폴더의 `Integrated Macro.app`을 실행하세요. 창 제목이 **통합 매크로 0.5.1**인지 확인하세요. 기존 설정 파일을 사용합니다.

## F8 좌표 지정

1. 예매창을 앞에 두고 **F7**로 연결합니다.
2. 앱에서 지정할 항목의 **F8로 지정**을 누릅니다. 설정창이 최소화됩니다.
3. 예매창의 대상 위에 마우스를 놓고 **F8**을 누릅니다. 3초 타이머는 없습니다.
4. 상단 표시창의 읽기·저장 결과를 확인합니다. 성공하면 좌표와 알림음이 나옵니다. 다른 항목은 다시 **F8로 지정**을 누르세요.

Mac 기능 키가 미디어 조절로 동작하면 **Fn+F8**을 사용하세요. 화면 기록과 손쉬운 사용 권한은 모두 필요하며, 권한 오류가 나오면 표시된 항목을 확인하세요.

## 예약 시각에 예매 버튼 클릭

**예매 준비 → 판매 시작 예매 버튼**을 F8로 먼저 지정하고 **예약 시작**과 판매 시작 시각을 설정·저장합니다. 예매창을 앞에 두고 **F1**로 시작하면 지정한 시각에 버튼을 한 번 클릭합니다.

이후 날짜·회차·캡챠는 직접 진행합니다. 실제 좌석 화면이 열리면 **F6**으로 진입을 확인합니다. 처음 보는 화면의 좌표·색상은 그 화면에서 지정하세요. 새 창이 열렸다면 F3으로 일시정지한 뒤 새 창을 F7로 연결하고 해당 화면을 지정한 후 F3으로 재개하세요. **F4**는 중지입니다.

## 실제 클릭 확인

같이 제공한 `input-check.html`을 Chrome으로 열고 페이지의 순서를 따르세요. 로컬 테스트에서는 서버 시간 보정을 끄고 약 30초 뒤로 예약합니다. 버튼 클릭 횟수가 1회가 되는지 확인할 수 있습니다.

## 검증 범위와 오류 기록

Rust 77개·JavaScript 38개 테스트, Mac 앱 빌드와 번들 서명 검사를 수행했습니다. 로컬 서명이며 Apple 공증은 아닙니다. 실제 사용자 화면의 F8·마우스 입력과 Windows 실행은 이 환경에서 확인하지 못했습니다.

대기 상태가 계속되면 표시된 마지막 단계·오류 코드와 아래 로그로 중단 지점을 확인할 수 있습니다.

`~/Library/Application Support/dev.integrated-macro.desktop/runtime-events.jsonl`

화면 이미지나 로그인 정보는 이 로그에 저장하지 않습니다. 브라우저의 날짜·회차·선점 결과를 자동 판독하는 연결은 아직 구현하지 않았습니다.
