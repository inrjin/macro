# 비원형 좌석 합침·분할 검토 — 소스 수정, 미배포

2026-10-21. 원형에 한정됐던 선택 기능을 반복되는 전체 외곽으로 확장했습니다.
추가 기능 **좌석 외곽으로 구분**은 기본 OFF이며, OFF의 기존 색상 탐색은 유지합니다.
기존 앱·ZIP, 버전 번호와 AGENTS.md는 변경하지 않았습니다.

## 변경한 동작

- 같은 화면에서 최소 6개 확인되는 전체 외곽을 학습합니다. 사각형·직사각형·타원·마름모·
  둥근 사각형·회전형 및 기존 원형을 합성 양성 사례로 검사했습니다. 모든 좌석이 가용 상태인
  화면도 학습에 사용할 수 있습니다. 인식 코드에 모양별 이름이나 고정 지름을 넣지 않았습니다.
- 한 좌석 안의 여러 색 조각은 전체 외곽 안에서 판단합니다. 얇은 연결선으로 붙은 좌석은
  따로 학습된 개별 외곽과 경계가 뒷받침될 때 분리합니다. 임의로 클릭 간격을 벌리지 않습니다.
- 중복 방지와 연석 판단에 실제 외곽 픽셀을 사용합니다. 기울어진 두 좌석의 외접 사각형이
  겹쳐도 빈 모서리를 같은 좌석의 일부로 간주하지 않습니다.
- 반복되는 흰색 선택 표시가 별도 좌석으로 학습되거나, 한 좌석의 잘린 조각을 여러 번
  클릭하던 재현 사례를 수정했습니다. 큰 하나와 작은 여러 개로 동시에 해석되는 영역은 보류합니다.
- 클릭 직전에도 원래 전체 외곽과 클릭점이 유효해야 합니다. 탐색 영역의 화면·설정이 바뀌면
  그 최신 프레임을 한 번 재분석합니다. JSON에는 이 클릭 근거를 보존하지 않습니다.
- 큰 연결 영역 내부의 빈 위치를 반복 검사하던 병목은 정확한 전경 픽셀 수 상한으로 걸러냅니다.
  기존 양성 판정 조건을 완화하지 않았습니다. 탐색 한도에 걸린 경우는 진단에 표시합니다.

수량 확인은 별도 **NOL 선택 좌석 수 확인** 옵션입니다. 외곽으로 구분하는 것만으로 실제
선택 증가를 증명하지 않습니다. 수량 확인 OFF의 기존 클릭 전달 기반 추정에는 무반응 클릭을
선택으로 셀 수 있는 한계가 그대로 있습니다.

## 상호 검토와 재현

구현 담당, 실제 Engine 호출 경로 검토 담당, 독립 영상·반례 검토 담당을 나눴습니다.
독립 렌더러의 좌석 소유 영역과 클릭·토글 결과를 기준으로 검사하며, 후보가 모두 사라지는
결과를 정상 좌석 인식 성공으로 세지 않았습니다.

재현 후 수정한 결함은 픽셀 가장자리 변화 누락, 반복된 흰색 표식의 잘못된 학습,
연결된 두 좌석을 큰 하나로 학습하는 문제, 열린 흰 줄의 조각 오인, 주변 상태가 달라졌는데
과거 클릭 근거가 통과하는 문제, 큰 빈 영역의 느린 탐색입니다. 세 번째 조각이 남는 문제는
소스 검토에서 찾아 먼저 수정했으므로 해당 테스트는 수정 전 실패 증거가 아닌 수정 후 회귀입니다.
실패 로그와 테스트 가정의 정정 기록을 보존했습니다.

## 최종 검증

최종 소스 127개 파일의 검사 전후 SHA-256이 같습니다. 세 검토자의 최종 검토 해시와도
일치합니다. 정확한 명령·로그 해시·보존 검사 결과는 [final-checks.json](final-checks.json)에 있습니다.

| 검사 | 결과 | 근거 |
| --- | --- | --- |
| Rust 전체 workspace | 400 통과, 0 실패, 수동 검사 4개 제외 | [로그](workspace-final.log) |
| JavaScript 전체 | 150 통과, 0 실패 | [로그](javascript-final.log) |
| 기존 제공 이미지 별도 실행 | 가용 2개 인식, 선택 표시 3개 제외; 통과 | [로그](provided-image-final.log) |
| 합성 최적화 벤치 별도 실행 | 2개 통과 | [로그](adversarial/final-performance.log) |

새 독립 영상 20개·Engine 통합 11개·클릭 근거 계약 2개는 Rust 전체 결과에 포함됩니다.
수동 제외 4개 중 제공 이미지 1개와 새 벤치 2개는 별도 실행했습니다. 변경하지 않은 기존
수량 증거 해시 비용 벤치는 이번에 재실행하지 않았습니다.

정적 합성 이미지에서 1,000개 가용 좌석 추출은 3회 중앙값 20.811ms,
변하지 않은 프레임의 첫 클릭 직전 검사는 0.492–0.544ms였습니다. 큰 빈 테두리 사례는
수정 전 1,457.875ms에서 수정 후 3.263ms로 줄었으며 각각 한 번의 측정입니다.
벤치 뒤 외곽 소스의 설명 주석만 바뀌었고 실행 코드 동일성을 별도 검토했습니다.
이 수치는 화면 캡처·변경 프레임 재분석·OS 클릭·사이트 응답 시간을 포함하지 않습니다.

## 남은 지원 한계

픽셀이 같은 단일 아령 모양 좌석과 연결된 두 좌석은 화면만으로 의미를 확정할 수 없습니다.
독립된 한 좌석의 예시 없이 연결된 쌍만 반복되는 화면도 두 좌석이라는 근거가 부족합니다.
넓게 합쳐진 외곽, 반복 부족, 속이 빈 좌석·큰 흰 글자, 배경 분리 실패 등은 보류될 수 있습니다.
이는 잘못된 클릭을 제한하는 동작이며 해당 배치에서 계속 좌석을 잡을 수 있다는 보장은 아닙니다.

외곽 증거는 지원 크기·반복·불투명도·탐색 한도가 있는 영상 휴리스틱입니다. 화면 획득 이후
실제 입력까지의 변화, 픽셀로 구별되지 않는 선택 상태, 실제 열 번호와 서버 선점 결과까지
증명하지 않습니다. 비원형 검증은 합성 이미지이며 실제 제공 이미지는 기존 원형 화면입니다.
실제 비원형 공연 화면, 앱 실행·네이티브 클릭, Windows 실행과 배포 빌드는 이번에 하지 않았습니다.
