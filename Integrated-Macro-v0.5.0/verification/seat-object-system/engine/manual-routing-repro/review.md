# Count-mode manual action review

The original exact runtime helpers were copied and linked to the actual production Engine in `probe.rs`. Exit 0 reproduces four incorrect behaviors for Normal booking with count verification ON and the original non-continuous policy: a manual selection action is advertised but ignored; after delivery the generic conflict cannot find a current candidate; with delivered A and queued B it reports undelivered B and is ignored; an automatic foreground hold does not expose the deliberate failure-report phase. An explicit DeliveredSeatResult for A is the positive control.

The smallest correction adds a default-false `Snapshot.selection_count_verification` flag without changing `optimistic_selection` or any automatic Engine transitions. Runtime hides/rejects manual selection under this flag, routes failure reports through delivered action IDs, and exposes deliberate reports only during automatic context recovery, not a user Pause. Entry/CAPTCHA/region/refresh confirmations remain original. The UI uses the same separate policy for count guidance, selected-color controls, optional failure/closed-dialog controls, and visual-watch messages.

`corrected/probe.rs` independently copies the corrected production helpers and links the current Engine. All four corrections pass, along with old-ACK/queued-candidate rejection and OFF/Entry/CAPTCHA/Region/Refresh controls. Both original and corrected source hashes, compiler commands and results are preserved. These are component-level tests, not Worker/native/browser execution.

Independent reviewer inspected the default-false model field and direct engine profile mapping. The implementer inspected the corrected runtime helpers, `confirm` guard, snapshot action list, selected-color guard, actual UI callers, and DOM payload tests. Generic failure still means the user's deliberate report about the latest delivered attempt; without semantic request identity it cannot identify an unrelated delayed server error. No new automatic failure-guessing policy was introduced.
