# 보류된 픽셀 마스크 비교 시제품

이 디렉터리는 검토 중 작성했다가 채택하지 않은 코드의 스냅샷이다. 현재 생산 코드나 배포 앱에 포함된 기능이 아니다.

시제품은 좌석 색상 연결 성분의 실제 픽셀을 가로 구간으로 보존하고, 사각형 안의 빈 공간 대신 실제 픽셀 교집합으로 중복을 판정했다. C/U형 성분의 빈 공간에 있는 별개 객체를 잘못 제외하던 사례는 해결했다.

그러나 선택 후 원래 고리 부분이 사라지고 빈 중앙에 같은 색 표식이 생기는 반례에서는, 기존 사각형 방식이 막던 동일 좌석 재클릭을 새로 허용했다. 외부 선택 상태를 모사한 검사에서 실제 선택 수가 부족한데도 완료를 요청했다. 이것은 기존 한계가 아니라 시제품이 도입한 회귀로 분류한다.

처음부터 보였던 다른 색상 성분만 예외로 인정하는 대안도 검토했다. 한 물리 좌석이 처음부터 여러 색 조각으로 그려질 수 있으므로, 초기 라벨을 의미상 다른 좌석의 증거로 삼는 것은 충분하지 않다.

따라서 시제품의 마스크 저장·비교·관련 생산 테스트는 원복했고, 별도로 입증한 연석 행 분리와 후보 캐시 수정만 채택했다. 이전 사각형 방식의 과도한 제외는 미해결로 남긴다. 원본 파일 해시는 `source-sha256.json`, 비교 실험과 최종 판정은 상위 검토 기록을 참고한다.
