# 좌석 코드 상호 리뷰와 회귀 검증

2026-10-21 · 0.5.9 이후 미배포 수정 소스 · 배포 빌드 없음

## 역할과 검토 범위

- `fix_cancellation_start`: 중복 판정 시제품·연석 행 분류 구현, 반박에 따른 수정과 원복.
- `input_adversarial_review`: 독립 코드 리뷰, 실제 추출기→엔진 회귀와 상태·호환성 검토.
- `seat_shortcut`: 픽셀 영상→별도 좌석 상태 모형 대조, 새로운 회귀와 처리 비용 검토.
- 주 담당: 런타임 호출부·후보 보관 수정, 독립 반박 조정, 최종 통합 검사와 소스 일치 확인.

리뷰어는 실제 코드와 호출부를 읽고 반례를 교환했다. 합의 자체를 성공 근거로 삼지 않았으며, 처음 통과했던 시제품도 새 회귀가 확인되자 채택하지 않았다.

## 최종 채택한 수정

1. **작은 별도 후보 때문에 연석이 분리되는 오류:** 같은 행의 두 좌석 사이에 다른 크기의 후보가 세로 중심 정렬 순서상 끼면 마지막 행만 검사하던 코드가 연석을 놓쳤다. 가까운 기존 행을 역순으로 찾되 첫·마지막 좌석의 행 조건과 거리 제한을 유지한다. [수정 전 실패](independent-before.log), [수정 후 독립 7개 회귀](independent-final.log).
2. **취소표 탐색 중 과거 후보 누적:** 런타임 캐시가 모든 관측 ID를 계속 보관했다. 현재 관측 후보와 아직 처리 중인 원래 후보만 보관하도록 변경했다. 1,000회 갱신 대조는 보관 수를 확인하는 단위 검사이며 실제 앱의 장시간 실행 검사는 아니다.
3. **선택 확인 중 원래 클릭점 덮어쓰기:** 같은 ID의 색상 모양이 변하면 캐시가 새로운 중심점으로 덮어써져, 확인 모드가 실제 클릭점과 다른 곳을 읽을 수 있었다. 처리 중인 후보는 원래 클릭점을 유지한다. 실제 5×5→8×5 합성 영상에서 동일 ID·다른 클릭점으로 재현했다. [캐시 수정 전 실패](runtime-cache-before.log), [수정 후 3개 회귀](runtime-cache-after.log).

## 채택하지 않은 변경과 반박

실제 색상 픽셀을 보존하는 마스크 시제품은 C/U형 외접 사각형의 빈 공간에 있는 별개 후보 누락을 해결했다. 그러나 선택 후 고리 색이 사라지고 빈 중앙에 같은 색 표식이 생기면 기존 방식이 막던 동일 좌석 재클릭을 허용했다.

| 동일 합성 장면의 독립 상태 모형 결과 | 클릭 수 | 실제 선택 수 | 완료 요청 |
| --- | ---: | ---: | --- |
| 기존 외접 사각형 판정 | 1 | 1 | 없음 |
| 픽셀 마스크 시제품 | 2 | 0 | 발생 |

[기존 방식의 근거](ring-oracle-before.log), [시제품의 근거](ring-oracle-mask-experiment.log).

이는 **새로 도입한 회귀**로 분류했다. 처음부터 존재한 다른 색상 성분만 예외로 인정하는 대안도 반박했다. 한 물리 좌석이 처음부터 여러 색 조각일 수 있으므로 초기 성분 라벨은 서로 다른 좌석의 증거가 충분하지 않다. 시제품은 [실험 스냅샷](mask-experiment/README.md)에 보존하고 생산 코드에서는 원복했다. 최종 `model.rs`·`vision.rs`·`engine.rs`는 검토 시작 전과 동일하다.

다른 가설도 실제 호출부로 반박했다. 구역별 동일 픽셀 ID 충돌 가설은 런타임이 `zone{index}:`를 붙이는 실제 경로에서 성립하지 않아 해당 수정은 하지 않았다.

## 미해결 및 검증하지 않은 범위

사각형 내부 빈 공간의 별개 후보까지 제외할 수 있는 문제는 남아 있다. 한 좌석의 초기 색 조각 분할, 붙은 같은 색 좌석의 병합, 얇은 좌석 누락·동일 색 비좌석 오인도 범용적으로 해결하지 못했다. 클릭 전달 수는 실제 사이트 선택 성공을 보장하지 않는다.

실제 공연 화면·전체 데스크톱 Worker·물리 입력·Windows 실행·배포 앱 반응 시간·장시간 운용은 이번 검증에 포함하지 않았다. 최종 판정은 채택한 수정의 코드 리뷰와 회귀 검증 완료이며, 전체 좌석 인식 기능의 완성이나 실사이트 예매 성공을 확정한 것이 아니다.
