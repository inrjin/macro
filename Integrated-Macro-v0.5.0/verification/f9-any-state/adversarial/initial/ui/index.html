좌석 바로 탐색은 공통 좌석 색상·좌석 영역을 사용합니다. 날짜·예매 진입·구역 선택을 건너뛰고, 후보가 없어도 설정한 간격으로 계속 탐색합니다. 반복 탐색을 이어가기 위해 F6을 누를 필요는 없습니다.

일반 예매의 ‘캡챠 Enter 후 구역부터 자동 진행’은 진입 이후 Enter를 기다립니다. ‘날짜·회차·예매 버튼 직접 진행’을 켜면 후속 버튼을 직접 누르고, 끄면 등록된 버튼을 순서대로 누릅니다. 캡챠를 다시 제출해도 날짜·회차·다음 버튼을 반복하지 않습니다.

‘NOL 캡챠 판단’을 켜면 진입 버튼 처리 뒤 첫 영문자·숫자 입력(Shift 가능)에서 왼쪽 아래 배경 색을 한 번 저장합니다. 첫 입력만으로 클릭하지 않고 이후 배경 색 변화가 확인되면 구역·좌석으로 진행합니다. 후속 입력·오답 재입력에도 기준을 유지하며 글자 내용은 수집·저장하지 않습니다. Enter 옵션보다 우선하며 취소표·좌석 바로 탐색에는 적용하지 않습니다.

같은 예매창의 다른 입력란은 구별하지 못합니다. 붙여넣기·자동완성만 사용하거나 자동 감지가 안 되면 캡챠를 직접 완료한 뒤 예매창에서 F9 ‘캡챠 이후 진행’을 누르세요. 이후 구역·좌석 탐색 중에도 F9로 재시도할 수 있습니다. 이미 좌석 화면에 들어왔다면 F5로 좌석부터 탐색하세요. 캡챠 정답은 자동 확인하지 않습니다.

좌석 선택 완료 버튼은 F8로 지정하세요. 한 구역 취소표 탐색도 이 공통 완료 버튼을 사용합니다. 클릭이 전달되면 매크로가 종료됩니다. 미지정이면 자동 완료 클릭 없이 기다리므로 사이트에서 직접 진행한 뒤 중지하세요.

반복 탐색과 취소표 갱신

한 구역 취소표는 현재 좌석 화면에서 공통 좌석 색상·좌석 영역으로 시작하며 일반 예매의 예약·진입·구역 선택 옵션을 적용하지 않습니다. 후보가 없어도 설정한 간격으로 화면을 계속 읽습니다. ‘현재 좌석 계속 탐색’은 버튼을 누르지 않습니다.

취소표에서 내부 버튼을 사용하려면 ‘한 구역 · 취소표 새로고침 버튼’을 선택하고 ‘취소표에서 버튼 사용’을 켠 뒤 버튼 좌표를 지정하세요. 브라우저 새로고침 키는 보내지 않습니다. 버튼 사용을 꺼도 화면 탐색은 계속됩니다.

한 구역 취소표 탐색에서는 재탐색 간격이 지나면 실패한 좌석을 다시 후보에 포함합니다. 사이트 갱신 완료를 직접 확인하거나 F6을 누를 필요가 없습니다. 원본 두 구역·위/아래 키 흐름의 화면 이동은 기존 F6 직접 확인을 유지합니다.

F1은 일반 예매, F2는 취소표 탐색, F5는 좌석 바로 탐색입니다. 선택한 실행 방식과 관계없이 해당 모드를 시작하며 화면에서 바꾼 현재 옵션도 저장해 적용합니다. F5는 브라우저 새로고침 용도가 아닙니다. 연결한 예매창을 앞에 둔 뒤 누르세요. 일부 Mac 키보드는 Fn 키와 함께 눌러야 합니다.

F1·F2·F5와 시작 버튼은 실행 중에도 다시 사용할 수 있습니다. 새 명령이 오면 이전 작업의 남은 입력을 취소하고 해당 모드로 시작합니다. F1은 예매 진입부터 다시 시작하므로 현재 좌석 화면만 탐색하려면 F5를 사용하세요.

F9는 수동 진입·캡챠를 직접 완료한 뒤 구역·좌석 탐색을 시작하며, 탐색 중에도 다시 눌러 재시도할 수 있습니다. F2·F5 실행 중에도 전환할 수 있고 등록한 진입 버튼을 다시 누르지 않습니다. 구역을 고르는 화면이면 F9, 이미 구역 안의 좌석 화면이면 F5를 사용하세요. 선택 완료 뒤에도 새 명령으로 화면을 다시 확인하고 재시도할 수 있습니다. 중지했거나 처음 실행하기 전에는 F1·F2·F5로 시작하세요.
