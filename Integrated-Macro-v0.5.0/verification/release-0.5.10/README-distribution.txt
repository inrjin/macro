통합 매크로 v0.5.10 · macOS 실험용 배포
Apple Silicon(arm64), macOS 13 이상

업데이트
1. 기존 앱에서 F4로 중지한 뒤 앱을 완전히 종료하세요.
2. 이 패키지의 Integrated Macro.app을 기존에 사용하던 위치에 복사·교체하세요.
3. 실행 후 화면의 v0.5.10과 저장된 옵션을 확인하고 브라우저를 다시 연결하세요.
   구버전과 신버전을 동시에 실행하지 마세요.
앱 식별자와 설정 저장 경로는 유지합니다. 기존 0.5.9 배포 폴더·ZIP은 보존합니다.

이번 변경
- 좌석의 색 조각을 중복 선택하는 문제와 같은 줄의 연석 우선 탐색을 개선했습니다.
- 원형뿐 아니라 사각형·타원·마름모 등 반복 외곽으로 좌석을 구분하는 선택 기능을 추가했습니다.
- 화면 전체의 ‘선택 좌석’ 문구·수량으로 실제 표시 매수를 확인하는 선택 기능을 추가했습니다.
- 수량의 일부 숫자, 설명 문구, 모순된 선택 없음 안내를 현재 매수로 확정하던 사례를 수정했습니다.
- 수량 확인을 사용하는 취소표 탐색은 같은 화면의 최신 좌석 후보를 반영한 뒤 진행합니다.

새 기능을 시험하려면
‘추가 기능’에서 ‘연석 우선’, ‘좌석 외곽으로 구분’, ‘NOL 선택 좌석 수 확인’을 각각 켤 수 있습니다.
세 옵션은 기본 OFF입니다. 이미 저장된 설정은 실행 후 직접 확인하세요.
좌석 외곽 기능에는 선택 가능한 좌석의 내부 색상을 등록하세요.
같은 형태의 외곽 근거가 부족하거나 크기가 모호한 후보는 클릭을 보류할 수 있습니다.

‘NOL 선택 좌석 수 확인’을 켜면 사이트 표시가 한 석 늘어난 뒤 다음 클릭을 허용하고,
목표 수량이 확인되어야 선택 완료를 누릅니다. 수량 위치를 고정하지 않습니다.
읽지 못한 결과를 0석으로 취급하지 않으며, 앱 상태에 보류 원인을 표시합니다.
‘작은 상단 상태 표시창’을 켜면 예매창 위에서도 확인할 수 있습니다.
지원하지 않는 글꼴·화면 구성이나 수량 변화가 불명확한 경우 대기가 지속될 수 있습니다.
이 옵션으로 동작하는 동안 직접 좌석을 선택·해제하면 기대 수량과 달라질 수 있습니다.
큰 합성 화면의 수량 판독만 약 240–260ms가 걸렸으며 전체 클릭 반응 시간은 미측정입니다.

단축키
F1 일반 예매 · F2 취소표 탐색 · F3 일시정지/재개 · F4 중지
F5 좌석 바로 탐색 · F6 원본 흐름 대기단계 확인
F7 브라우저 연결 · F8 좌표 지정 · F9 캡챠 이후 진행
Mac 키보드 설정에 따라 Fn과 함께 눌러야 할 수 있습니다.
캡챠는 직접 입력하며, F9는 직접 완료한 후 사용하세요.

검증 범위와 제한
자동 검사·서명·패키지 무결성 결과는 verification/의 기록을 확인하세요.
실제 예매창에서 0→1→2석 전환과 OS 클릭을 검증한 배포는 아닙니다.
Windows 실행 및 배포, 모든 좌석 외곽·글꼴·배치에 대한 지원도 확인하지 않았습니다.
사이트 표시 수량만으로 개별 좌석의 서버 선점이나 최종 예매 성공을 보장하지 않습니다.
선택 완료 버튼 전달 이후 결제·최종 성공 확인은 하지 않습니다.

앱은 로컬 ad-hoc 서명이며 Apple 공증을 받지 않았습니다.
업데이트 후 권한 승계는 보장하지 않습니다. 입력·화면 읽기가 실패할 때만 앱 진단에 따라
시스템 설정의 손쉬운 사용·화면 기록·입력 모니터링 항목을 확인하고 앱을 다시 실행하세요.
일괄 권한 초기화는 필요 없습니다.

문제가 생기면 실패 시각과 앱의 ‘실행 기록’을 남기세요.
세부 기록: ~/Library/Application Support/dev.integrated-macro.desktop/runtime-events.jsonl
로그는 용량 제한이 있으므로 실패 직후 보존하는 편이 좋습니다.
