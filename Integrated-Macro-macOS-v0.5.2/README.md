# 통합 매크로 0.5.2 · F8 수정 검증 빌드

Apple Silicon Mac, macOS 13 이상용입니다. 기존 앱을 ⌘Q로 완전히 종료한 뒤
이 폴더의 `Integrated Macro.app`을 실행하고 창 제목의 0.5.2를 확인하세요.
기존 설정 파일을 사용합니다.

## 이번 수정

- F8 좌표 채집은 연결한 창이 마우스 아래 실제로 보이는지 확인합니다.
  매크로 앱에 키보드 포커스가 남았다는 이유만으로 읽기를 거부하지 않습니다.
- 다른 창이 가렸거나 다른 예매 팝업이면 좌표를 저장하지 않고 이유를 표시합니다.
- 실패가 ‘입력 대기’로 덮이지 않습니다. 재시도·저장 성공 시 이전 오류를 지웁니다.

## 사용 순서

1. 실제 예매창을 전면에 두고 **F7**로 연결합니다.
2. 앱에서 필요한 항목의 **F8로 지정**을 누릅니다. 설정창이 최소화됩니다.
3. 연결한 창의 대상 위에 마우스를 놓고 **F8**을 누릅니다.
4. 지정 완료 좌표 또는 오류 코드를 확인합니다. 실패 후에는 F8로 재시도할 수 있습니다.
5. 다른 예매 팝업으로 바뀌었다면 그 창을 전면에 두고 F7로 다시 연결한 다음
   해당 항목의 **F8로 지정**을 다시 누르세요.

실제 자동 클릭을 시작할 때는 연결한 예매창을 활성화하고 **F1**을 누르세요.
좌표 읽기와 달리 실제 입력은 전면 창 검사를 유지합니다. **F4**는 중지입니다.
예약 실행은 **판매 시작 예매 버튼**을 지정해야 합니다. 날짜·회차·캡챠는 직접 진행하고
실제 좌석 화면에서 F6으로 진입을 확인합니다.

## 확인된 범위

Rust 77개, JavaScript 46개(실제 UI 코드의 오류→재시도→좌표 표시 검사 포함),
네이티브 창 상태 18개 재현 검사와 Swift arm64/x86_64 검사 결과를 확인했습니다.
최종 앱 빌드·서명·소스 일치 결과는 `verification/`에 기록합니다.

**실제 사용자 Chrome 창의 F8·화면 캡처·마우스 입력은 아직 검증하지 못했습니다.**
이 환경의 화면·입력 권한은 없고 격리 Chrome 검사도 차단됐습니다.
따라서 실전 사용 준비가 완료된 배포판으로 표시하지 않습니다. 로컬 서명이며 Apple 공증은 아닙니다.

동봉한 `input-check.html`은 실제 예매 없이 클릭 횟수를 확인하는 로컬 페이지입니다.
오류 로그는 `~/Library/Application Support/dev.integrated-macro.desktop/runtime-events.jsonl`에 남습니다.
